# UHF FM 무전기 (만능기판·브레드보드 실험용, 아마추어 430–440 MHz)

이 문서는 `radio_build = uhf_breadboard` 템플릿(`ai_eda/design/rf/t_breadboard.py`)이 만드는 무전기를 손으로 조립하기 위한 안내서입니다. 상용급이 아니라 **실험해서 동작을 확인하는 수준**이 목표입니다. 프로그래머블 소자(마이컴, PLL, FM 송수신 모듈)는 쓰지 않고, 트랜지스터와 연산증폭기로만 만듭니다.

> **먼저 읽을 것 — 법규**
> - 직접 만든 송신기는 KC 적합성평가를 받지 않았습니다. **생활무선(447 MHz 면허 면제) 채널에서는 절대 송신하지 않습니다.**
> - 이 무전기는 **아마추어 무선국 허가** 조건 안에서, 430–440 MHz 아마추어 대역의 허가된 주파수·출력·전파형식으로만 씁니다. 국내 아마추어 대역 사용계획과 허가 조건은 이 문서에서 확인하지 못했습니다 [UNVERIFIED].
> - 안테나를 달기 전에 반드시 **50 Ω 더미로드**에 연결하고 불요발사(스퓨리어스)를 확인합니다(아래 조정 순서 6단계).

## 1. 전체 구성

```
           ┌──────────── 송신 (TX/RX 스위치를 TX로) ─────────────────────────────────────────────┐
 마이크 → TL071 증폭(+다이오드 리미터) → TL071 저역통과(3 kHz) → 편이 트리머 → 가변용량 다이오드
                                                                                │
   36 MHz 수정 VXO(2N3904) → ×3 BF199(108 MHz) → ×2 BFR92A(216 MHz) → ×2 BFR92A(432 MHz)
   → 3공진기 대역통과 → A급 출력단 BFR92A(약 30 mW) → L 정합 → 5차 저역통과 → T/R 스위치 → SMA
                                                                                │
           ┌──────────── 수신 (TX/RX 스위치를 RX로) ────────────────────────────┘
 SMA → T/R(λ/4) → 공통 베이스 RF 증폭 BFR92A → 초재생 검파 BFR92A(자기 소멸 약 190 kHz)
     → TL071 증폭 → TL071 저역통과(3 kHz, 소멸 신호 제거) → 볼륨 → TL071 + BD139/BD140 → 스피커 8 Ω
```

| 블록 | 부품 번호 | 내용 |
|---|---|---|
| 전원 | 1xx | 9 V 배터리, 전원 스위치, 1N5817(역접속 보호), TX/RX 슬라이드 스위치, L78L05 두 개(V5T 송신용, V5R 수신용) |
| 송신 오디오 | 2xx | 일렉트릿 마이크, TL071 ×2, 소프트 리미터 1N4148 ×2, 편이 트리머 RV201, 가변용량 바이어스 |
| 송신 RF | 3xx | 수정 VXO, ×3·×2·×2 체배기, 3공진기 대역통과(CT304–CT306), 출력단, L 정합, 5차 저역통과 |
| T/R 스위치 | 6xx | 1N4148 직렬/병렬, 집중정수 λ/4(L601, C601, C602), SMA J601 |
| 수신 RF | 4xx | 공통 베이스 RF 증폭 Q401, 초재생 검파 Q402, 재생 트리머 RV401, 동조 트리머 CT401 |
| 수신 오디오 | 5xx | TL071 ×3, 볼륨 RV501, BD139/BD140 출력단, 스피커 J501 |

- **채널:** 하나로 고정입니다. 수정 주파수 = 반송파 ÷ 12입니다. 36.000 MHz 기성품을 쓰면 432.000 MHz가 되고, 다른 주파수는 수정을 주문 제작합니다(기본파 모드, HC-49/U). 432.000 MHz가 국내 아마추어 대역 사용계획에서 FM 송신에 맞는 주파수인지는 확인이 필요합니다.
- **설계 근거:** 433.92 MHz SAW 발진기도 검토했습니다. 하지만 ngspice 시뮬레이션에서 SAW의 C0를 통해 505 MHz로 자유 발진하거나 아예 기동하지 않아, 수정 ×12 방식을 택했습니다. 36 MHz 수정 VXO는 기동 여유가 약 3배입니다.

## 2. 이 저장소에서 만들어지는 것

```bash
ai-eda new uhf_bb --dir ./uhf_bb
ai-eda run ./uhf_bb/ir.json --answer radio_build=uhf_breadboard --answer "carrier_frequency=432 MHz" \
   --answer modulation=FM --answer "input_voltage=9 V" --answer application=amateur_radio_experiment --answer jurisdiction=KR
ai-eda run ./uhf_bb/ir.json --answer confirm_design=yes     # 표를 확인한 뒤
```

결과 폴더에는 다음이 생깁니다.

- KiCad 회로도(`.kicad_sch`)와 2층 PCB(`.kicad_pcb`, 200 × 100 mm, 블록별 영역에 배치·배선)

- 3D 미리보기
- 한국어 단계 보고서 4종(`reports/`)

이 PCB는 만능기판 대신 기판을 주문해 실험하고 싶을 때 쓰는 대안입니다. KiCad ERC/DRC는 kicad-cli가 있는 PC에서 실행해야 합니다.

**이 폴더에 들어 있는 것** (2026-11-03, KiCad 10.0.6 라이브러리, ngspice-42 실행 결과):

- `example/`: 432.000 MHz, 9 V로 만든 회로도, PCB, 프로젝트 파일, BOM, CPL, 이론·회로·최종 보고서(`.md`)
- `board.svg`: 배선된 기판 그림(배선 1334개, 비아 56개, 84개 넷 모두 연결)
- `wiring.md`: **배선표.** 블록별로 각 넷에 연결할 핀(`R301.1`, `Q301.2(B)` …)을 나열합니다. 컴파일된 회로도는 기호를 선 대신 넷 이름표로 잇기 때문에, 납땜할 때는 이 표를 기준으로 합니다.
- `perfboard_all.svg`, `perfboard_<블록>.svg`: 만능기판 배치도. PCB 배치를 2.54 mm 격자로 옮긴 그림입니다. 각 블록 안에서 부품이 신호 순서대로 줄지어 놓입니다(송신 RF는 VXO → ×3 → ×2 → ×2·대역통과 → 출력단·저역통과 순서로 한 줄씩).
  - 선 색: 빨강 전원, 파랑 RF, 회색 일반 신호. 접지 기호는 접지 버스에 연결한다는 뜻입니다.
  - 그림 안의 선은 연결 관계를 나타낼 뿐, 실제 배선 경로가 아닙니다.

## 3. 브레드보드 → 만능기판 순서

432 MHz는 브레드보드에서 동작하지 않습니다. 브레드보드는 줄 사이 용량(수 pF)과 접점 인덕턴스 때문에 엉뚱한 회로가 됩니다. 그래서 아래 순서로 나눠서 만듭니다.

| 단계 | 어디에 | 무엇을 | 확인 |
|---|---|---|---|
| 1 | 브레드보드 | 전원부: 9 V, 1N5817, 스위치 두 개, L78L05 두 개 | V5T·V5R이 5 V인지(멀티미터) |
| 2 | 브레드보드 | 수신 오디오: TL071 ×3, BD139/BD140, 볼륨, 스피커 | AF_RAW에 1 kHz 5 mV를 넣고 스피커에서 소리가 나는지. 출력 직류 약 4.5 V |
| 3 | 브레드보드 | 송신 오디오: 마이크, TL071 ×2, 편이 트리머 | 마이크에 대고 말할 때 TXA에 0.5–1 Vpp, 큰 소리에 ±0.6 V 근처에서 클리핑 |
| 4 | 만능기판(동판 접지 권장) | VXO와 ×3 단 | 주파수 카운터나 SDR로 36 MHz와 108 MHz 확인 |
| 5 | 만능기판 | ×2, ×2, 대역통과, 출력단, 저역통과, T/R | 더미로드에서 432 MHz 출력 |
| 6 | 만능기판 | 초재생 수신부 | 재생 트리머로 '쉬' 잡음이 나는 지점, 근처 송신기 신호 수신 |

검증된 오디오·전원부는 브레드보드에서 만능기판으로 옮겨도 되고, 브레드보드에 둔 채 짧은 선으로 이어도 됩니다.

**만능기판 요령 (RF 단):**

- **접지:** 기판 한 면 전체를 접지로 씁니다. 동박 기판을 조각내 붙이거나, 굵은 주석선으로 접지 버스를 만듭니다. 모든 바이패스 커패시터의 접지 리드는 1–2 mm 이내로 짧게 합니다. 432 MHz에서는 선 1 mm가 약 1 nH입니다.
- **BFR92A:** SOT-23이므로 SOT-23→DIP 변환 기판에 올리거나, 동판 위에 '데드버그'로 직접 납땜합니다.
- **트리머:** 라이브러리에 THT 트리머가 없어 KiCad 기판은 Murata TZC3(SMD)입니다. 만능기판에는 같은 범위의 THT 세라믹 트리머(2–10 pF, 3–20 pF 등)를 씁니다.
- **0.2 pF 결합:** 대역통과의 결합 C319·C320(약 0.18 pF)은 기성품이 없습니다. 절연 전선 두 가닥을 1–2 cm 꼬은 '기믹' 커패시터로 만들고, 조정 중에 길이를 잘라 맞춥니다. 탭 C318·C321(약 0.6 pF)은 0.5 pF 부품에 기믹을 더하거나, 같은 방법으로 만듭니다.
- **블록 사이 배치:** 단과 단 사이는 일렬로 놓고, 출력단과 VXO는 서로 멀리 둡니다.

| L601 | λ/4 직렬 코일 | 18.4 nH | 지름 4 mm, 약 2.5턴 |
| L401 | 초재생 탱크 | 22 nH | 지름 4 mm, 약 2.7턴 |

| L301, L303, L305, L309, L602, L402 | 급전·RF 초크 | 100 nH–1 µH | 작은 페라이트 비드에 가는 선 6–10턴, 또는 공심 3 mm 20–35턴 |

## 5. 조정 순서

**필요한 장비:**

- 멀티미터
- 50 Ω 더미로드(1 W, 무유도 저항 51 Ω 또는 100 Ω 두 개 병렬)
- 다이오드 RF 프로브
- 주파수 카운터 또는 RTL-SDR(스펙트럼 확인용)
- 가능하면 아마추어 핸디 무전기

1. **전원:** TX/RX 스위치를 각 위치에 두고 V5T·V5R이 5 V인지 확인합니다. TX일 때 배터리 전류는 대략 수십 mA입니다.
2. **VXO:** RF 단 급전 저항 R307 이후를 떼어 두고 VXO만 켭니다. 36 MHz(f_c/12)에 발진하는지 SDR로 확인하고, CT301로 중심 주파수를 맞춥니다. 수정 기본파의 끌림 폭은 수 kHz입니다.
3. **×3 탱크:** CT302로 108 MHz가 최대가 되게 맞춥니다. 72 MHz나 144 MHz에 맞추지 않도록 SDR로 주파수를 확인합니다.
4. **×2 탱크:** CT303으로 216 MHz를 최대로 맞춥니다.
5. **대역통과:** CT304 → CT305 → CT306 순서로 432 MHz를 최대로 맞춘 뒤, 처음부터 한 번 더 반복합니다. 그래도 출력이 너무 작으면 결합 기믹 C319·C320을 조금 길게 합니다.
6. **출력과 스퓨리어스(안테나 없이):** J601에 더미로드를 답니다. 출력단 Q305가 손으로 만졌을 때 뜨겁지 않은지(약 0.15 W 소모) 확인합니다. SDR로 396 MHz(f_c − f_X), 468 MHz(f_c + f_X), 864 MHz(2차 고조파)가 432 MHz보다 충분히 낮은지 봅니다. ngspice 고정 회로망 계산으로 대역통과는 각각 약 −45 dB, −35 dB(432 MHz 대비)이고, 저역통과는 2차 고조파에서 약 −29.5 dB, 3차에서 약 −49 dB입니다(코일 Q 80 가정). 허가 조건의 불요발사 기준을 만족하기 전에는 안테나를 달지 않습니다.
7. **편이:** 아마추어 핸디로 수신하면서 RV201을 조정합니다. 목소리가 찌그러지지 않는 최소 편이가 목표로, 협대역 ±2.5 kHz 또는 광대역 ±5 kHz 중 허가 조건에 맞춥니다.
8. **수신:**
   1. RV401을 돌려 스피커에서 '쉬—' 하는 초재생 잡음이 막 들리기 시작하는 지점에 둡니다.
   2. 다른 무전기로 432 MHz를 송신하고, CT401을 돌려 잡음이 줄어들며 신호가 들리는 지점을 찾습니다.
   3. FM은 정확히 반송파에 맞추면 잘 안 들립니다. 조금 비켜 맞추는 기울기 검파로 소리가 납니다.

## 6. 검증 범위 (파이프라인이 확인한 것과 아닌 것)

**ngspice로 확인한 것** (일반 모델 카드 기준의 원리 검증이며, 실제 부품 측정이 아님):

- 오디오 증폭 이득(1 kHz)
- 3 kHz Sallen-Key 저역통과 응답
- 기준 전압과 가변용량 바이어스
- 출력단 직류점과 이득
- 소멸 주파수(190 kHz)에서의 감쇠
- RF 수동 회로망: 체배 탱크 2개, 대역통과, L 정합, 저역통과, T/R 스위치(송신/수신 상태)

**실험 항목** (`ir.rf.lab_items`): VXO 기동과 주파수, 체배기 구동, 출력 전력, 불요발사, 초재생 수신 감도와 소멸, 스피커 출력, T/R 손실

- 1N4148은 PIN 다이오드가 아니므로 T/R 스위치의 실제 손실·격리는 측정해야 합니다.
- 일렉트릿 마이크의 극성은 PUI Audio 데이터시트와 대조하지 않았습니다 [UNVERIFIED].
